# 1.6.2 Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix six things the owner hit on 1.6.1: chat sends refused with `prompt-busy` although nothing of theirs was on the terminal's prompt row; a pending session rename typed into the middle of what they were writing; a never-prompted session missing after a restart; the trust-folder dialog not taking keys after a tab switch (Task 4); the session header's words sitting high beside the picture; no line between the Pokédex strip and the session list.

**Architecture:** The page already reads Claude Code's prompt row from its own xterm buffer (`src/chat/promptRow.ts`). It now also reads which cells are dim: Claude Code draws a placeholder and a greyed suggestion with SGR 2 (verified on 2.1.325: `ESC[2mTry "fix lint errors"` vs typed `ESC[mhello`), typed text never. So the screen alone tells a suggestion from typed text, and the ledger in `electron/chatInput.cjs` is only the fallback when attributes are missing. The same reading gates the `/rename` the widget types. Restore stops dropping transcript-less Claude sessions: `create()` starts them fresh under the same id. The header and the panel are CSS (plus one wrapper element).

**Tech Stack:** Electron main (CommonJS), React 18 + TypeScript + Vite, xterm.js 5 buffer API (`IBufferCell.isDim()`), vitest, the harness `tests/visual/shots.mjs`.

**Spec:** this plan (bugs reported in chat on 2026-11-16; evidence: `%APPDATA%\spawn\logs\spawn.log` 08:30:36 prompt containing `/rename Spawn (New)`, 08:32:22 `chat send refused (prompt-busy)`; restore: session `dcc3fbfd…` hooked at 08:27:58, quit with n=7, back with 6, no transcript).
