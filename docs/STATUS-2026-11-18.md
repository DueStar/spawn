## 2. 이틀 동안 들어간 것 (1.7.0 + 1.8.0)

### 채팅: 터미널로 돌아갈 일 없애기
- **선택 창 카드**: 훅이 못 잡는 터미널 대화상자(`/model` 확인, 폴더 신뢰, plan 선택지 등)를 화면에서 읽어 카드로. ↑/↓를 한 칸씩 보내며 화면으로 확인한 뒤 Enter. 제목은 `?`로 끝나는 질문 줄.
- **질문 카드**: 질문 여러 개(최대 4개), 다중 선택, plan 승인(승인 · 계속 계획하기).
- **모델·모드 메뉴**: 입력란 아래. 모델은 `/model 별칭`, 모드는 Shift+Tab을 보내고 아래줄 표시로 확인.
- **입력란에 남은 글**: "가져와서 이어 쓰기 / 지우고 보내기".
- **전체 보기**: 잘린 답·메시지·생각·도구 출력·셸 출력을 기록에서 다시 읽어 표시.

### 채팅: 입력과 보기
- `!` 셸 모드, 결과는 작은 터미널 블록.
- 빈 입력란에 Claude Code 추천 다음 말(Tab/→로 채움, 자동 전송 안 함).
- `@` 파일은 입력란 위 뱃지, 보낸 메시지 위에도 뱃지.
- 대기 중 메시지 목록 펼치기, 불렛 자동 이어 쓰기(Shift+Enter).
- 진행 설명(thinking `updates`)이 기본 화면에도 보임.
- 마크다운 블록·새 .md 파일은 문서 카드(문서 / 원문).
- 일하는 포켓몬 통통 + 후광(움직임 줄이기 설정 존중).

### 앱 UI
- 세션 탭 최대 3개(끌어 놓기 또는 Ctrl+클릭), 채팅/터미널 전환은 앱 전체에 하나.
- 왼쪽 목록 자동 정렬: 확인 필요 → 일하는 중(시작 순) → 쉬는 중(최근 순). 설정에서 끔.
- 업데이트 버튼 오른쪽 위 노랑, 설정 스위치 노랑, HP 바 길이 고정, 조력자 위치.
- 글자 크기 80~130%(10% 단위).
- 아이콘: Phosphor bold 하나, 12 / 14 / 16px.
- 이어하기 목록에서 세션 삭제 → `~/.spawn/trash` 7일, 되돌리기.
- 디자인 시스템 페이지 `?system`(토큰·아이콘·컨트롤·채팅 컴포넌트 실물).

### 고친 버그
| 증상 | 원인 | 고침 |
|---|---|---|
| 보낼 때마다 "세션 기록 파일을 찾지 못했어요" | claude-mem 훅이 12초 걸려 기록이 늦게 써짐(기준 5초) | 15초 + 기록이 오면 배너 바로 지움 |
| "방금 끝난 답이 기록에 없어요"가 다시 읽기 전까지 남음 | 3초 검사 실패 후 다시 안 봄 | 늦게 온 답이 오면 지움 |
| 이어 쓴 세션에 "확인 안 된 버전" 배너 | 옛 버전 줄 때문에 고정 배너 | 확인된 버전 줄이 오면 지움 |
| 터미널엔 있는 Claude 설명이 채팅에서 빠짐 | 진행 설명이 thinking 칸에 저장됨 | `update` 표시로 기본 화면에 보임 |

## 3. 실제 세션에서 아직 확인 안 된 것

테스트(2,457개)는 통과했지만, 실제 Claude Code에서 써 봐야 아는 것:
- [ ] `/model` 메뉴 → 확인 카드에서 Yes → 모델이 바뀌는지
- [ ] 모드 메뉴로 계획 모드 등으로 바뀌는지
- [ ] 다중 선택 질문 답(고른 이름을 `, `로 이어 붙임 — **추정**)
- [ ] plan 카드의 승인 / 계속 계획하기
- [ ] 세션 탭 끌어다 놓기
- [ ] "지우고 보내기"가 입력란을 깨끗이 비우는지

문제가 생기면 `%APPDATA%\spawn\logs\spawn.log`의 `[chat]` 줄부터 확인.

## 5. 다음 후보: 폰에서 쓰기 (기억만, 아직 시작 안 함)

PC가 켜져 있고 로그인돼 있으면 안드로이드에서 spawn을 쓰기. Claude 앱 원격 제어가 headroom 때문에 막히는 문제를 피하려는 것.

| 단계 | 방법 | 되는 것 | 크기 |
|---|---|---|---|
| 1 | Tailscale + 웹앱(PWA), 처음에 PC 화면 QR로 기기 등록 | 세션 목록, 채팅 보기·보내기, 카드·선택 창 답 | 2~3일 |
| 2 | Capacitor로 감싼 APK | + "확인 필요 / 일 끝남" 푸시 알림 | +2일 |
| 3 | Supabase 중계 | Tailscale 없이 밖에서 | +3~4일, 보안 설계 |

원칙: 폰은 채팅의 좁은 통로(보내기, 카드 답, 선택 창 키)만 씀, 기기별 등록과 끊기, 3단계는 끝단 암호화.
